# IT Audit Framework – PCI DSS Case Study

**Course:** MIS 415 – Information Systems Audit and Control  
**Institution:** George Mason University – Costello College of Business  
**Focus:** PCI DSS Compliance | IT Security Controls | Risk Assessment

---

## Overview

This project presents a multi-domain IT audit framework developed for a 
fictional accounting services firm handling sensitive cardholder data. 
All audit deliverables are aligned with **PCI DSS (Payment Card Industry 
Data Security Standard)** requirements and cover policy writing, network 
security controls, and database auditing.

---

## Deliverables

### HW2 – Data Protection & Cryptography Policy
- Policy for PCI DSS Requirements 3 & 4
- Covers secure storage of cardholder data, AES-256 encryption, 
  TLS 1.2+ transmission standards, and role-based access control (RBAC)

### HW3 – LAN Domain IT Audit Checklist
- Internal network audit covering device inventory, user access controls, 
  workstation security, patch management, and incident response

### HW4 – LAN-to-WAN IT Audit Checklist
- Perimeter security audit covering firewall configuration, router security, 
  IDS/IPS, VPN with MFA, and compliance with PCI DSS data-in-transit requirements

### HW5 – Microsoft SQL Server Audit Checklist
- Database security audit covering access control, login security, 
  Transparent Data Encryption (TDE), audit logging, and backup procedures

---

## Skills Demonstrated

- Policy Writing & Procedure Development
- Network Security Controls (LAN, WAN, VPN, Firewall)
